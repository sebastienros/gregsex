## Native host surface and generic projection

Typed `Pcre2Pattern`/`Pcre2Workspace` operations preserve native-width semantics. Native Match accepts caller pair capacity>=1: rc0 is successful short-vector reporting, positive rc is one above highest participating group; surplus pairs remain untouched. Complete success publishes unset/empty distinctly. Native no-match/error leaves caller pairs unchanged; partial publishes only group0, other slots are undefined upstream and not asserted. Start/end are independent; `(?=ab\K)` with approvedextra may report(2,0), a valid typed result. MARK is a stable immutable native-width payload index(-1none), not per-search transcoded text. Byte/char mark/callout views are materialized at compile time under the same budget.

Source-native UTF validation inspects the visible source window required by originalstart+longestlookbehind (including word boundaries), checking its start boundary. Existing shared APIs keep whole-input validation/full capture destination/clear-on-failure statuses. **Generic projection is an explicitly requested WholeSubjectValidated domain**, admitted at compile/factory boundary and immutable thereafter. It rejects invalidUTF/no-check configurations, UTF code-unit atoms and possible lookaround-reset ranges with a capability diagnostic pointing to typed parity. It never invokes an engine and discards a valid awkward result, never maps reversed/partial/invalidUTF matching to invalidinput/no-match, and never extends shared status enums. Generic operations do not accept typed partial/callback controls; the approved typed surface remains available for all these capabilities.

Native substring copy/length/get semantics use explicit subject+nativepairs, with required terminator capacity/errors, duplicate name first-participating lookup and ambiguous name→number diagnosis. Native8 owned output is bytes, not lossy strings. Pattern metadata includes every semantic INFO query, immutable duplicate name entries/numbers and callout site/string enumeration; excluded physical INFO requests diagnose capability rather than return fabricated zeros. COPY_MATCHED_SUBJECT explicitly creates bounded owned native-width data, separately accounted with old/new buffers before growth, exposed as readonly until next workspace operation/disposal. Without that option no subject span is retained after a call. Native pointers/context/allocator lifecycle/layout remain excluded, while managed lifetime/ownership replacements are explicit.

All-match iteration is a labelled managed host session, not a native iterator ABI. It exclusively owns one workspace/cumulative budget, retains no borrowed subject, and receives/revalidates original input each Next. Empty matches retry NOTEMPTY_ATSTART+ANCHORED at the same nativeoffset; if that fails, advance one native character with CRLF/UTF source rules; terminal empty is emitted once. For valid reset-start results that do not progress (reversed pair or end<=current bound), preserve the result, then use the same bounded retry/advancement rule; never loop indefinitely or turn the result into no-match. \G compares **immutable invocation SearchStart**, never mutable CandidateStart/ReportStart. Each iterator native search gets its actual invocation start while the outer operation's budget/deadline never resets. Partial/error/limit ends iteration with its visible status. Workspace overlap/disposal/reentrancy is rejected; no copyable pooled lease is hidden in an enumerator.

Typed substitution admits all source options, replacement grammar/named/numeric/extended conditional references/case forcing, global progression, MATCHED precomputed results, replacement-only and native overflow sizing. Source overflow estimates with callbacks may over/underestimate; expose reported capacity honestly, bounded retries retain the same cumulative safety budget. Destination capacity/terminator and failures follow source-defined output rules, not shared capture rules. Materialization/output growth are explicitly bounded host costs, separate from warmed native boolean/range/capture work. No .NET replacement parser is reused.

## Callbacks and resource policy

Match callouts are width-native readonly ref-struct views: originalsubject+length, completedcapture pairs, mark presence/units, numeric/string identity, capture_top/last, start_match/current/pattern/next positions, stringoffset/length and version2 STARTMATCH/BACKTRACK flags. Numeric0 and empty string callouts remain distinguishable. AUTO_CALLOUT sites/order and optimizer-caused suppression are source-observable obligations. Matchcallback0 continues; positive fails this path and explores alternatives; negative aborts with the exact signed return (including negative values outside the native enum). No callback means source-ignored callouts.

Substitute callout version0 sees initialized proposed output+range/currentcaptures/count:0accepts, positive rejects and continues globally, negative rejects/stops and copies remaining original input, returning substitutions/matches processed as source specifies. It is **not** a matchcallback negative-abort error. Case callback lower1/upper2/title-first3 receives native input/output, supports overlap, returns required size or managed-1 representing nativeSIZE_MAX→REPLACECASE. Overflow simulations/invocation suppression/size estimates follow pinned source. Callback exceptions propagate as user exceptions; readonly views cannot escape/mutate executor state; sameworkspace use is forbidden. Caller user state is owned by caller and registered per operation, never stored in an immutable pattern. Poll budget/cancel/deadline before/after callbacks; arbitrary callback code is not preemptible by an engine timeout.

Finite defaults: existing RegexCompileLimits retain65,536native/source units,256nesting,1Mnodes/classes,65,536intervals,1,024groups including0,10Mwork,64MiBpeak/retained; native grammar capture/repeat maximum65535 applies independently. Sourcefixed lookbehind max65535 and all version-specific restrictions remain lowerer proof obligations. Zero caller/directive work/depth/heap is a denial, never unlimited. Overrides cannot raise retained safety ceilings; pattern LIMIT minima reduce them, including LIMIT_RECURSION alias/depth and heapKiB conversion with checked arithmetic. Native work/heap/stack counter equality is explicitly excluded. Cancellation/deadline/resource/error are distinct from no-match.

Logical depth is **live16-slotframes + live6-slotwindows**; each subroutine reserves a Subroutine frame. Shared Push/Pop maintains CallDepth; no module may bypass MaxDepth by writing counters/slot buffers itself. Both frame/window admissions enforce smaller/zero depth before physical capacity. Prepared capacities (4,096frames/65,536undo/4,096windows/512Unicode scratch defaults) are separate from logical limits. Integer partitions: state64+16frames+6windows, capture2×GroupCount, scratch4undo+UnicodeScratch. Full **typed callback pair staging** is a separate workspace-owned GroupCount array, charged conservatively32header+16bytes/pair in RequiredStorage. It is never caller shortoutput, integer-cast storage, percallback allocation or an uncounted hidden array. Shared PrepareCallbackPairs publishes group0unset during matching and complete final pairs for substitution; upper undefined capture slots are cleared as a safety disposition. All sizes/retained sums/expansions/copies are checked/admitted before allocations. Payload copies use the same CompileBudget and one immutableplan.

Every input read/validation unit, opcode/child visit, frame/window push/pop/read/truncate, capture write/undo, callback staging slot/dispatch, candidate retry, lookbehind/backreference/script/grapheme step and host output/iteration operation is charged cumulatively. Native source counters need not match these units. No assertion/subroutine/candidate constructs a fresh RunState; outer host iteration/substitution retains work/starttime/cancellation across inner searches. Resource unwind leaves caller output per source policy and makes workspace reusable. Logical failures latch once; teardown clears active cursors without pretending unrun cleanup work passed.
