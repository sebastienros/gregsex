# POSIX Issue 7 C-byte contract v1

Pin **Issue 7, 2018 edition** (POSIX.1-2017 text), XBD chapter 9/7.2/7.3 and XSH regex interfaces. Official source identities and independently authored table/corpus digests are retained in [source-manifest.json](../../test/corpora/posix/sources/source-manifest.json) and [contract-lock.json](../../test/corpora/posix/sources/contract-lock.json). Later interpretations or Issue 8 additions do not silently amend this profile. Corpus source links identify normative clauses, not oracle guesses. No copyrighted source pages are redistributed.

## Provider and representation

The canonical table row for each byte 0..255 is `byte:u8, classMask:u16le, foldToLower:u8, collationOrdinal:u8`, in byte order; class bits follow `PosixCharacterClass`. SHA256 is `PosixLocale.C.DataDigest` and is locked with the fixture table. NUL has its ASCII cntrl membership in data but is never admitted by pattern/subject validation. For ASCII: upper=A–Z, lower=a–z, alpha=both, digit=0–9, alnum=alpha/digit, blank=TAB/SPACE, cntrl=0–31/DEL, space=TAB/LF/VT/FF/CR/SPACE, print=32–126, graph=33–126, punct=graph except alnum, xdigit=0–9/A–F/a–f. Fold A–Z to a–z, all else unchanged. Collation ordinal is the byte value, singleton primary equivalence. Bytes128–255 are admitted opaque unclassified bytes, a human-approved GregsEx domain disposition, not a universal C codeset claim. Every byte consumes one unit and yields byte offsets; malformed UTF-8 has no special meaning here.

`PosixProfile` is an immutable closed descriptor. `PosixLocale.TryGet` resolves only exact C/POSIX names and gives an unsupported-feature diagnostic at the original alias span for other requests. Cache keys include edition, dialect, flags, provider ID AND digest, input kind and safety options. No extensible public provider ABI is promised. Future locales require a new versioned provider/dataset/corpus decision.

Generic `RegexPattern.Parse/TryParse` default options remain Utf16; POSIX callers must explicitly request `new RegexCompileOptions(RegexInputKind.Bytes)`. Typed `PosixFunctions` factories default null options to Bytes; explicitly incompatible options fail. Character-pattern errors use UTF16CodeUnits, byte errors use Bytes, representation errors are zero-length option diagnostics. Exact native byte matching never round-trips patterns/subjects through strings. The parser must check full pattern domain and input kind before grammar publication; every inspected native unit costs compile work.

## Classification register

Issue 7 section9.1 distinguishes explicitly invalid constructs from general grammar/semantic violations with undefined results. The profile's strict policy chooses errors for the latter. XSH gives symbolic error identities, but does not standardize native integer values or English error text. The independent conformance lane must preserve these distinctions rather than learn expected errors from one libc.

| Construct/condition | Source classification | Frozen named-profile disposition / typed identity |
| --- | --- | --- |
| Unknown/nonexistent collating element, BRE reference without required preceding closed group | Invalid (9.3.5/9.3.6) | InvalidCollatingElement / InvalidBackreference; Invalid disposition. |
| Unknown class name | Invalid class type in XSH error inventory; no extra C locale charclasses | InvalidCharacterClass / Invalid disposition. |
| Dangling escape, unbalanced delimiters, malformed/overflow/reversed interval | Grammar violation, Undefined where not explicitly invalid by9.1 | TrailingEscape / UnbalancedParenthesis/Bracket/Brace / BadInterval; UndefinedRejected. |
| Adjacent repetition, repetition in ERE forbidden initial/anchor/operator positions | Explicit Undefined (9.3.6/9.4.3/9.4.6) | BadRepeat / UndefinedRejected. BRE leading `*` is literal, including first group position after optional `^`. |
| Empty ERE group/alternative; empty BRE group (outside grammar) | Undefined (9.4.3 /9.1) | BadPattern / UndefinedRejected. |
| ERE escaped ordinary char including `\1`, `\n`, `\]`, `\}`; BRE `\+`, `\?`, `\|`, `\d`, `\0` | Undefined in Issue7; often extensions | BadPattern / UndefinedRejected; capability PX-019 identifies strict policy. Issue8 reclassifications do not apply. |
| Recognizable lookaround/noncapturing/atomic/modifier/named group/GNU/BSD extras | Nonstandard extension, often also undefined grammar | UnsupportedFeature + BadPattern / ExtensionRejected. The recognized feature is named; no alternate flavor interpretation. |
| Bracket backslash | Defined literal (9.3.5) | Accept literally, including `[\]`; no escape processing. |
| BRE anchors first/last in group | Optional (9.3.8) | Enabled. Escaped `\^`/`\$` remain literal. |
| Matching/nonmatching lists and classes admitting multi-character elements | Unspecified in9.3.5 | No such elements in this provider; C-only path is singleton. Invalid symbol `ch` is rejected rather than silently treating it as two elements. |
| Range outside POSIX locale | Unspecified | Unsupported locale; never assign portable range behavior. |
| Equivalence/class range endpoints | Equivalence endpoint Unspecified; class endpoint outside permitted grammar | InvalidRange / UnspecifiedRejected for equivalence, UndefinedRejected for class. |
| Reverse/empty range | Unspecified (9.3.5 allows empty or invalid) | InvalidRange / UnspecifiedRejected. |
| Shared/chained range endpoint e.g. `[a-m-o]` | Undefined (9.3.5) | InvalidRange / UndefinedRejected. |
| Bare bracket edges `[.x.]`, `[=x=]`, `[:x:]` (first/last matching marker with >=3 elements) | Unspecified (9.3.5) | BadPattern / UnspecifiedRejected; explicit double-bracket `[[:alpha:]]` is ordinary standard class syntax. |
| Entire empty pattern | Outside nonempty formal grammar; native practice varies | Ratified GregsEx empty-match behavior at earliest admitted start; labelled GregsEx provenance, not normative portable grammar. |
| Embedded NUL, char-pattern units>255 | Outside admitted named domain | InvalidPatternEncoding / PatternDomain; subject InvalidInput/InvalidInputDomain at first NUL across whole subject. |
| Changed compile/execution ambient locale | Undefined native interface state | Impossible managed binding; compiled provider immutable. |
| Multiple diagnostics/English regerror message/preg after native compile failure/native free misuse | Unspecified/undefined native interface conditions | Deterministic managed first-error traversal, symbolic identities/ASCII messages, existing managed lifecycle exceptions. No binary/C pointer ABI claim. |

Finite safety ceilings may reject valid inputs via explicit resource diagnostics; they cannot masquerade as strict syntax rejection. All defined syntax through the provider's 255 repeat bound is admitted under sufficient allowed budgets. Ordinal/source-specific diagnostics are deterministic; conformance accepts the source-permitted error category rather than requiring native code/message identity when detection order varies.

## Shared IR and internal ABI

`Contracts/Posix/LaneContracts.cs` / `PosixProgram.cs` freeze an owned, bottom-up binary syntactic tree and immutable sets. Nodes: Empty, Literal, Class, Any, Sequence, Alternative, Repeat, Capture, Backreference, Start, End. Children refer to earlier IDs; each nonroot has exactly one parent, root is last. Group numbering is opening-source order, group0 parent=-1, other parent IDs identify nearest containing capture. Sources contain child sources, sequence/alternative children retain lexical order. This tree is independent of ordered `SemanticProgram`. Classes are 256-bit nonNUL sets normalized including IgnoreCase-before-complement and negative-list Newline exclusions; Any is distinct from Class. Repeat retains counters rather than requiring expansion. No lazy/minimal/tagged acceleration opcode is included.

`PosixProgram.TryCreate` validates ownership/nesting/sources/group closure and copies all retained inputs only after cumulative budget admission. MaxInstructions counts nodes; MaxClassRanges counts retained 256-bit sets in this lane, a documented unit distinct from XML intervals; MaxCaptureGroups includes group0. Validation scratch is admitted/released under the same CompileBudget; copied plan bytes stay charged. Node tree depth and parser syntactic depth both obey MaxNestingDepth. Captures may appear only once, refs are BRE/1–9 and refer to a closed preceding group's original span. No branch target/program can bypass source/capture validation. Normalized case data is bound before factory invocation.

`IPosixLocaleData` supplies exact frozen masks/fold/collation spans of256 entries and class/symbol lookup at compile boundaries. Parser owns provider implementation and compile domain/grammar work; it returns only PosixProgram. Executor factory verifies provider ID/digest and table dimensions; no per-character virtual locale lookup. Parser independently budgets every input-dependent temporary/group/class allocation, old+new live buffers and repeat arithmetic. Common default limits remain unchanged (65,536 native pattern units, depth256, 1m nodes, 65,536 sets, 1,024 groups, 10m work, 64MiB compile/plan/workspace); a 256-byte supported pattern minimum is covered by default representation/pattern limits.

`IPosixExecutor.Search` takes original bytes, lower-bound startAt, Boolean/Range/Captures, execution flags, a positive `PosixExecutionCapacity`, shared RunState, full captures and out range. `GetRequiredCapacity` takes the same operation/capacity. Default capacity=4,096 explicit frames/65,536 history events; zero/default capacity invalid. Internal tests can reduce limits. Engine chooses its conservative checked partition formula for capacity admission; all frame/history/capture/scratch logical partitions are documented and accounted by required capacity. Both logical ceilings are enforced with oversized physical arrays. Insufficient history/frame storage => LimitExceeded/WorkspaceCapacityExceeded. Workspace memory admission and checked overflow precede input validation. There is no grow-on-demand hidden list, recursion or input-sized stack allocation.

Selection obligations: enumerate/compare admissible paths at earliest start until whole winner and necessary subpattern priorities are established, using retained occurrence histories; a bounded reference verifier is allowed before tagged acceleration. Compare enclosing subpatterns before children and left siblings before right siblings, with longest participation at each earlier choice and matched-empty before absent. Repeat history must preserve successive subpattern choices, null-repetition restrictions and containing-iteration identities. For the frozen `(a*)*`/`aa` witness, whole and group1 are(0,2); an extra optional empty iteration is not fabricated to replace that group with an empty tail. Required zero-progress iterations may satisfy exact/minimum counts or sole nullable acceptance, and are finite/charged; optional zero-progress cycling terminates. The empty-subject/miss witness preserves required matched-empty participation. Equal observable paths may use stable source order only after all required priorities tie; do not invent a portable result for a source ambiguity. In any disputed case conformance reduces the disagreement and obtains a source-based permitted set or explicit approved disposition before claiming completion. Backreferences participate during path feasibility, not after accepting an impossible regular winner; no-match of an unmatched reference and final-parent register scope must be preserved. Tag dominance/deduplication requires proof against this verifier; no pruning by only `(node,offset)` or final capture vectors. Final reports are projected from the selected history using XSH parent scoping, not rank-comparing only last registers.

One cumulative RunState covers whole-subject NUL validation, candidate starts, every node/frame/history event, transition, byte read/reference compare, history ranking step and output write. Candidate/fallback retries never reset work/deadline/cancellation. Initial zero-work poll even on immediate acceptance. Any earlier candidate that exhausts cannot be skipped for a later match. Failure clears only logical capture output; range default; workspace remains reusable. NoMatch is a semantic conclusion, not a resource fallback.

## Typed host and generic integration

Typed `PosixFunctions.Parse` and `TryParse` accept character or byte patterns with a PosixProfile and optional compile options. `RegExec` accepts a workspace, byte subject, caller match span, execution flags, and match options; `RegError` formats a symbolic error into a caller byte span. Typed Parse throws PosixRegexException; generic Parse retains RegexParseException.

RegExec requires a POSIX workspace, accepts only known flag bits, searches at start0 in original span, and reports RegexSearchStatus. Span length is native nmatch:0 performs Boolean, 1 requests group0 range, larger requests complete internal register selection then publishes first min(nmatch,GroupCount) endpoints, fills excess entries (-1,-1). NoSub or nmatch0 leaves ALL output untouched on every status. Other Match publishes once after complete success; NoMatch or execution failure fills all requested entries(-1,-1), a labelled GregsEx error-publication disposition since native failure contents are not guaranteed. Native unused groups(-1,-1) map generic absent capture(false,0,0); participating empty groups have equal nonnegative endpoints. Partial nmatch must never alter winning whole/submatch selection or lose reference registers. NoSub may use boolean selection because no output is requested.

Generic POSIX pattern.IsMatch/workspace.IsMatch/Find/FindCaptures use flags=None, byte input, common output and failure precedence. Generic FindCaptures on NoSub throws NotSupportedException before output/work admission; other operations remain available. GroupCount always describes syntactic groups, including under NoSub (managed metadata extension where native re_nsub is unspecified). RegExec cannot use a temporary full capture array per call: integration reserves internal publication registers in the workspace partitions and invokes a bounded owned hook. Reentrancy/disposal/arguments/options validation precedes output, capacity admission then initial poll/full-subject validation, then match/selection. Generic capture-short-destination handling remains common API; native nmatch is partial output, so no DestinationTooSmall solely for native match span length.

RegError accepts only defined symbolic codes except None, emits a stable unspecified ASCII English diagnostic, returns required byte count including trailing NUL; empty span writes nothing, short spans truncate to size-1 and terminate, exact/oversized span leaves tail untouched. It does not require native preg state or expose native integer values. Common finite budget failures retain their specific RegexDiagnostic/RegexExecutionFailure identity and are never labelled REG_ESPACE merely because a configured safety ceiling was reached. Managed Dispose releases workspace ownership and throws on active use; patterns are immutable managed owners rather than manually freed regex_t values. REG_EXTENDED is represented by typed dialect; shell grep/sed behavior, replacement/splitting/lastIndex and C binary ABI are outside this regex-library host contract.

## Corpus and verification boundary

`posix-fixtures-1` retains exact integer pattern/subject units, provider/digest, profile, compile/execution flags, classification, capability IDs, provenance, operation/start/destination, limits, expected statuses/ranges/full captures/native endpoints/diagnostics and permitted outcome arrays. The strict JSON reader rejects unknown/missing fields, unsupported contract versions, duplicate IDs, out-of-range units/coordinates/flags and contradictory participation/publication. The fixture JSON Schema 2020-12 is versioned. ContractVectors and LocaleTable byte hashes are frozen in contract-lock; downstream coverage must execute every seed and expand independently, never edit seed expectations to match an engine.

Conformance pins two independently built libc families (glibc+musl recommended, exact builds must be selected and hash-observed during intake), oracle options/locale/environment/platform, source/binary identities and timeout/work caps. Inspect source and compare results including each capture, all nmatch/NoSub modes and diagnostics. Disagreements, high-byte/provider choices and undefined forms are classified before passing; not averaged or silently quarantined. Corpus generation never copies GregsEx outputs into expectations. No libc artifacts are shipped. Pinned actual oracle identities are a dependent intake deliverable, not an invented contract-tested version.

Verify semantic selection, diagnostics, resource ceilings, lifetime/concurrency, and BDN MemoryDiagnoser costs with stable prepared storage and separate cold/output costs. Default execution remains NativeAOT-safe. See [verification.md](verification.md).
