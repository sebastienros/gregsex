# XML regex contract v1

## Editions and data

Pin [XSD 1.1 Part 2, Recommendation 5 April 2012](https://www.w3.org/TR/2012/REC-xmlschema11-2-20120405/), Appendix G; [F&O 3.1, Recommendation 21 March 2017](https://www.w3.org/TR/2017/REC-xpath-functions-31-20170321/), section 5.6/C.1; [XML 1.0 Fifth Edition](https://www.w3.org/TR/2008/REC-xml-20081126/) character/name rules; and explicitly selected Unicode 16.0.0 (default) or 17.0.0. One `XPathProfile` serves XPath and XQuery. These are regex/function profiles, not a schema validator or query evaluator. XML 1.1, XSD 1.0, and permissive extensions are outside v1.

GregsEx interprets production 82 as excluding an unescaped class backslash, and `w` as the single-character complement of P/Z/C. These interpretations are not W3C-approved errata. Archived issues 29443/30268 were unresolved in the pinned source audit; do not silently change these profile semantics.

Descriptors: `XsdProfile.Id=Xsd11`, `XPathProfile.Id=XPath31`, both with immutable `UnicodeVersion` and `DataId=Unicode-16.0.0+XML-1.0-5e` or `Unicode-17.0.0+XML-1.0-5e`. Version choice is GregsEx policy, not a claim that W3C mandates Unicode16. Pin categories from UnicodeData.txt (including algorithmic First/Last ranges and implicit Cn), blocks from Blocks.txt, and full default lowercase/uppercase using UnicodeData.txt plus unconditional SpecialCasing.txt. Exclude locale-conditional/Turkic/Lithuanian casing. Do not substitute ambient .NET categories, culture, ECMAScript folding or loose property aliases. Input snapshots' exact byte sizes/SHA256, dated URIs and licenses are in [source-manifest.json](../../test/corpora/xml/sources/source-manifest.json). Retain original Unicode inputs/notices, use reproducible generation, emit output digests, and independently verify completeness. A download hash is not generator verification.

Unicode 17 sources are separately retained under `tools/unicode/xml/17.0.0/`,
with their own `inputs.json`, `outputs.json` and independent audit. Existing
Unicode 16 source/corpus pins are unchanged.

Block lookup uses the selected Unicode version's normalized names: remove whitespace/underscores from Blocks.txt names, preserve case/hyphens. Explicit compatibility aliases are `Greek`→0370–03FF, `CombiningMarksforSymbols`→20D0–20FF, and `PrivateUse`→E000–F8FF ∪ F0000–FFFFD ∪100000–10FFFD (historical XSD inventory). No arbitrary Unicode aliases, case folding or whitespace insertion into a block escape. Current normalized supplementary private-use block names keep their own Blocks.txt endpoints; the legacy `PrivateUse` alias uses the historical endpoints above. The generator freezes the exact name/range inventory. Any syntactically valid but unknown XSD `IsBlock` name has the standard all-character default for BOTH positive and negative escapes. XPath instead reports FORX0002. `Is` with no following name and unknown category codes are syntax errors, not unknown-block defaults.

## Text, offsets and error precedence

Character patterns use original UTF-16 source coordinates. Byte-pattern overloads are rejected; XML has no raw-byte subject language. Generic borrowed searches admit strict scalar UTF-16 and strict UTF-8; native ranges are UTF-16 units or bytes. XML Char is TAB/LF/CR, 20–D7FF, E000–FFFD and10000–10FFFF. TAB/LF may form one normalized interval9–10; 10–13 crosses illegal controls. XML NameStartChar/NameChar use the Fifth Edition productions, including colon and supplementary10000–EFFFF; name admission is narrower than XML Char. Scalar surrogates, malformed UTF-8, NUL and other illegal XML characters are never repaired. Supplementary noncharacters admitted by XML Char are not rejected through an extra “assigned Unicode” rule. Pattern literals must themselves satisfy the XML domain (including q); use InvalidPatternEncoding with original source coordinates for violations.

Preserve prior argument/lifecycle→capture destination→no-growth capacity→initial cancellation/deadline→full subject→scalar start boundary precedence. Full subject validation precedes Match/NoMatch, even for an early literal hit. Report the first offending native input offset. Malformed encoding gives InvalidInput/InvalidEncoding. Well-formed encoding outside XML Char gives InvalidInput/InvalidInputDomain; the new enum member is appended as value9, preserving all existing failure values. Original-input look visibility and LF anchors are retained; slicing at startAt is forbidden. XPath startAt is a scalar-boundary lower bound; XSD startAt must be0 (otherwise argument error). No whitespace-facet normalization, entity expansion, XML parsing or Unicode normalization occurs.

The typed functions consume strings and treat null optional input as the F&O empty sequence/empty string. Required pattern/replacement null is a programmer argument error. Host functions reject compile options requesting UTF-8/raw input, since their string subject has UTF-16 storage; they never transcode behind the caller's back. Generic UTF-8 execution remains available through pattern/workspace APIs.

FORX0001 means invalid flags, FORX0002 invalid regex, FORX0003 an empty-matching pattern for replace/tokenize/analyze-string, and FORX0004 malformed replacement. Preserve the namespace `http://www.w3.org/2005/xqt-errors`, original source domain Pattern/Flags/Replacement and UTF-16 coordinates. Invalid input, cancelled/timed-out execution, compile limits and host ceilings remain GregsEx failures, not false results or FORX syntax failures. `XmlRegexDiagnostic` wraps the shared diagnostic; standard function failures throw `XPathRegexException`; compile-resource exceptions retain `RegexParseException`; runtime failures retain `RegexExecutionException`. `XPathHostException` distinguishes result/output/memory exhaustion. Function validation order is flags→profile/representation/domain/pattern parsing→empty-input matching check where required→replacement grammar→subject/execution/output. This deterministic ordering is GregsEx policy when multiple independent errors coexist. Cancellation/deadline/work spans compilation-independent execution checks and all successive searches in one host call; it never resets for each match. No partial result is published on failure.

## Shared program and internal ABI

`Contracts/Xml/LaneContracts.cs` and `XmlProgram.cs` form a separate ABI, sharing only the existing budget/workspace/range/source types. No ECMA AST/executor/category interface is a dependency. Bottom-up tree nodes retain ordered Sequence/Alternative, Repeat (Max=-1 unbounded), Literal/Class, XPath Capture/Backreference/Start/End and original source ranges. XSD has group count1 and no XPath-only nodes. GroupParents stores syntactic capture nesting, root group0 parent=-1. The validator rejects cycles/DAG reuse/orphans, malformed operands/intervals/source spans/depth, illegal XML literals, incorrect group ancestry/open numbering and references not yet closed. It admits every validator scratch/final copy through the same CompileBudget and releases temporary bytes on every exit. Normalized class slices are sorted, disjoint and nonadjacent, clipped to XML Char; classes may be empty. Subject reader dispatch is statically specialized by char/byte, not a virtual call per character.

`IXmlUnicodeData` returns immutable data spans and exact category/block lookup. `IXmlClassAlgebra` performs budgeted union/subtraction/complement/case variants at compile time. Case data keys identify full lower/upper mapped sequences; identity singleton keys use scalar IDs and expansion keys occupy a disjoint generated namespace. Compare equality of either mapping, not a single ECMA fold key, and do not invent a transitive closure beyond the defined variants. Normalize intervals after clipping; implement negation/subtraction after literal/range variant expansion. `IXmlTextReader` validates complete subjects and scalar boundaries, charging native units. Malformed encoding outranks a boundary error; the first malformed/domain violation encountered wins.

`IXmlCompiler` consumes only char patterns and already verified shared data/algebra. `IXmlExecutorFactory` produces a bound executor from a validated plan under retained compilation limits. `GetRequiredCapacity(operation,frameCapacity)` and `Search(...,operation,frameCapacity,...)` receive the same finite positive ceiling. Public  bindings use a fixed4096-frame ceiling; no public Compile/Workspace/MatchOptions or host parameter promises caller configurability. Runtime stores/forwards that admitted ceiling; Search checks logical partition lengths against required capacity and enforces frameCapacity even when underlying arrays contain spare slots. Its computed bytes must fit workspace ceilings. Only internal module tests/custom bindings may explicitly request a smaller/larger finite ceiling, using the same value in both ABI calls; spare buffers never increase the public ceiling. Exhaustion is a capacity/resource status, never silent growth in a no-growth call. Executors must publish exact deterministic partition equations and test spare-capacity and small-ceiling behavior in tests. Contract compile samples prove parameter plumbing, not future layout correctness.

## Public data and functions

Public data types are immutable descriptors, flags, diagnostics, host limits, and results. `XsdFunctions.IsValid` and `XPathFunctions.Matches`, `Replace`, `Tokenize`, and `AnalyzeString` expose typed operations. Optional flags default to empty. Generic Parse/TryParse/workspace APIs share the same profile semantics.

AnalyzeString's immutable `XPathAnalyzeResult.Input` plus read-only preorder `XPathAnalyzeNode` records represent the typed tree. Top-level Match/NonMatch nodes cover the original input; Group/Text descendants have earlier ParentIndex and UTF-16 subranges. GroupNumber is positive only for Group; unmatched groups are absent, empty participating groups remain present. Each group appears at most once per match. Retain all final participating captures: use a containing participating syntactic parent when possible, otherwise the nearest participating containing ancestor, ending at the match. Order siblings by input position. Thus `((a)|b)+` on `ab` retains group 2=`a` and group 1=`b` as match children. Replacement/backreference registers are unchanged; textual leaves partition their parent string without duplication. The host validates this structure, scalar boundaries and budgets before invoking the internal copying constructor; that constructor is not a public arbitrary-tree validator. This flat representation preserves nesting and permits nonrecursive traversal. F&O namespace/local-name constants are public. It does not introduce XML serialization or mutable DOM ownership.

Host limits default to1000000 results/nodes,16777216 materialized UTF-16 units and64MiB conservatively accounted live bytes. Includes node arrays/read-only views, strings, intermediate output and old/new growth overlap. Cold parse/workspace/output allocations are permitted and separately reported. Host loops charge the same cumulative budget through empty-pattern precheck, each match, replacement parsing/copying, token/node production and cleanup; user cancellation/deadline cannot reset. Output length/count/peak bytes have separate structured failures. Borrowed booleans/ranges/caller-buffer captures use prepared no-growth workspaces with controlled allocation costs as specified in [performance.md](performance.md).
