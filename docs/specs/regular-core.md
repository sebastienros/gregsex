# RegularCore contract v1

The experimental `RegularCore-1-experimental` profile uses fixed ASCII data identity `GregsEx-ASCII-1`, algorithmic encoding rules, and no ambient Unicode category or culture tables. Its subset is independent of the stable flavor profiles. [Compilation](compilation.md), [performance](performance.md), and [verification](verification.md) define shared backend and validation requirements.

## Input and pattern admission

| RegularCoreMode | Legal subject storage | Consumption and validation | Native offsets |
| --- | --- | --- | --- |
| UnicodeScalars | Utf16 or Utf8 | Strict scalar values; paired UTF-16 surrogates form one scalar; malformed UTF-16/UTF-8 fails over the whole subject | UTF-16 units or bytes |
| Utf16CodeUnits | Utf16 only | Each 16-bit unit is data, including lone surrogates | UTF-16 units |
| RawBytes | Bytes only | Every value 0..255 is data | Bytes |

The only core flags are None and DotAll. Pattern char overloads are admitted in all three modes, independently of subject storage. Scalar patterns require well-formed UTF-16; raw char patterns admit only code units 0..255; neither path uses replacement encoding. The byte-pattern overload is admitted only for RawBytes and preserves each original byte. Scalar UTF-8 subjects use the char-pattern overload in core; UTF-8 byte-pattern syntax remains unadmitted. Profile/representation mismatch is UnsupportedRepresentation, not no-match. Invalid enum/option values are argument errors.

startAt must be within [0,input.Length]. Scalar starts inside a UTF-16 pair or UTF-8 sequence return InvalidInput / InvalidStartBoundary after whole-subject validity succeeds. Code-unit/raw-byte starts admit every storage boundary. The original subject is always visible to anchors; no sliced-subject search is permitted. Encoding failure identifies the first malformed sequence's starting native offset, not a replacement character or an arbitrary following continuation. EOF is a valid start boundary.

## Complete experimental syntax inventory

This subset is unrelated to any stable ECMAScript/PCRE/XML/POSIX compatibility claim. These are capability IDs for downstream fixture manifests.

| Capability | Admitted syntax and exact behavior |
| --- | --- |
| RC-001 literals | Legal alphabet elements; concatenation; empty pattern/alternative/group. Unescaped regex metacharacters are syntax, never lenient literal fallback. |
| RC-002 classes | `[abc]`, inclusive `[a-z]`, `[^a-z]`, union of literals/ranges/predefined escapes. `-` is literal only first/last or escaped; `]` and `[` must be escaped as elements. Empty classes are invalid. Range endpoints must each denote one alphabet element and ascend. No subtraction/intersection/nesting. Negation complements the legal profile alphabet and excludes surrogate values in scalar mode. |
| RC-003 escapes | Escaped punctuation `\\ . ^ $ | ? * + ( ) [ ] { } -`; `\n \r \t \f \v`; exact two-digit `\xHH`, exact four-digit `\uHHHH`. Scalar mode also admits `\u{H...}` with 1..6 hex digits and one legal scalar. Unit/raw modes reject that braced form as unsupported. Numeric `\0` means NUL only when no decimal digit follows. Out-of-domain literal/escape values are InvalidPatternEncoding. Unknown/malformed escapes are InvalidSyntax. |
| RC-004 predefined ASCII | `\d=[0-9]`; `\w=[A-Z a-z 0-9 _]`; `\s=[U+0009..U+000D,U+0020]`. Uppercase D/W/S are alphabet-relative complements. ASCII data is fixed in all modes. |
| RC-005 dot/anchors | Dot consumes one element except U+000A; DotAll includes it. `^` means absolute subject offset 0; `$` means absolute input.Length, with no terminal-newline exception. Anchors in classes are ordinary elements except leading negation. No multiline policy. |
| RC-006 alternatives | `a|b`, priority in source order; search selects earliest candidate start, then the first successful ordered path. |
| RC-007 repeats | `* + ? {n} {n,} {n,m}`, greediness by default; suffix `?` selects lazy priority. Counts are nonnegative decimal integers, max>=min; checked overflow/expansion is a compile limit failure. Every emitted copy charges instruction/work/memory budgets before growth. Malformed/repeated quantifiers are InvalidSyntax; possessive forms are UnsupportedFeature. |
| RC-008 groups/captures | Capturing `(...)` and noncapturing `(?:...)`. Captures numbered by opening parentheses, group zero included. Final capture only; no names/history. Entering each repeat iteration clears all captures nested in its body; final participating iteration determines values. Unmatched and matched-empty are distinct. |

Recognized excluded constructs report UnsupportedFeature with their source span: backreferences (including numeric digits 1..9), word boundaries/`\b`/`\B`, properties `\p`/`\P`, lookaround, named/atomic/conditional/branch-reset groups, inline flags, possessive repetition, class algebra and flavor-specific extensions. Invalid malformed syntax stays InvalidSyntax. Bare malformed braces do not become literals. A syntactically valid construct in another flavor does not acquire that flavor's semantics. Parser fixtures must cover positive, negative and boundary cases for every row, independently of any BCL baseline.

## Public policy and precedence

`RegexCompileOptions`, `RegexCompileLimits`, `RegexMatchLimits` and `RegexWorkspaceOptions` use validated immutable constructors, rather than mutable object-initializer bags. Defaults: UTF-16 scalar subjects, interpreted mode, 65,536 pattern units, nesting 256, 1,000,000 instructions, 65,536 total class intervals, 1,024 groups including zero, 10,000,000 compile work units, 64 MiB retained plans, 64 MiB peak compilation memory, 10,000,000 execution work units, 64 MiB workspace memory. Values must be positive and finite; no unlimited sentinel. Overrides can only reduce pattern match ceilings. Timeout, if supplied, is positive; null keeps work budgeting and cancellation without an elapsed deadline.

Compilation precedence is configuration/profile admission, full pattern-domain validity, pattern-length admission, then source-order parse/lowering with budget checks immediately before the charged work/allocation. Nested invalid constructs do not excuse consuming beyond a budget. Expected failures carry native pattern units, precise source spans and no formatted message on success. Internal InvalidProgram indicates a compiler defect; integration must raise an internal failure, not relabel it user syntax or fall back to another regex engine.

Workspace operation precedence:

1. Lifecycle admission: disposed use and concurrent/reentrant use throw. Validate representation overload, numeric startAt and option ceilings/timeouts as ordinary argument errors; workspace use remains exclusive throughout the operation.
2. For Captures, check `groups.Length >= GroupCount` before capacity admission or input work. A short destination is untouched, match is default and LastFailure is DestinationTooSmall with RequiredCapacity=GroupCount and zero consumed work.
3. Admit all executor partitions and workspace bytes before validation. No-growth insufficiency is LimitExceeded / WorkspaceCapacityExceeded; exceeding the memory ceiling is WorkspaceLimitExceeded. Growth is allowed only by explicit workspace policy and remains outside the prepared no-growth scope. Reserve/growth is checked and transactional; failure retains the previous usable buffers.
4. Reset LastFailure and initialize one RunState/budget for the operation. Call TryCharge(0, startAt) before any early return, including empty subject, empty program, immediate Match/NoMatch. Cancellation precedes deadline, which precedes work exhaustion at every poll.
5. Validate the entire subject, charging every inspected native unit; then validate scalar start boundaries. InvalidEncoding wins over an interior start boundary found in an invalid subject. Never return an early match before trailing UTF-8 validity is established.
6. Search with the original subject and the same budget. On success initialize every logical group slot, absent slots to false/0/0, and leave excess destination capacity untouched. On NoMatch or failure default the range and clear the logical GroupCount slice; excess capacity remains untouched. Cleanup after failure is bounded by admitted capacities and does not retry exhausted work. LastFailure is None on successful/no-match operations.

The convenience boolean API uses a temporary owned workspace and may allocate. It throws RegexExecutionException for execution failures and returns false only for NoMatch. No shared global scratch. Disposal is idempotent; Reserve and matching after disposal throw; separate workspaces can use an immutable pattern concurrently. Iterator loops emit a terminal empty match once; after a nonterminal empty match advance one legal element from match.Index. After a nonempty match continue at its end. Caller-loop advancement is tested; failed searches terminate iteration.

## Internal ABI and memory accounting

The compiled source of truth is `src/GregsEx/Contracts/LaneContracts.cs`, `Budgets.cs` and `src/GregsEx/IR/SemanticProgram.cs`.

- Text readers implement `ITextReader<char>` and `ITextReader<byte>` with static methods. Validate sees the complete subject/profile/RunState; it returns NoMatch for successful validation, sets Failure for invalid/limited/cancelled/timed-out input. TryRead is used only after validation and returns an element and its positive native width, or false/width=0 at EOF. Caller charges one read unit. Class operations use immutable CharacterClass interval spans and the profile's legal alphabet. No virtual call per character is required.
- The compiler implements IFlavorCompiler char/byte TryCompile. It retains no borrowed pattern, reports expected diagnostics, lowers ordered decisions/captures/anchors and returns only a SemanticProgram admitted through TryCreate. Byte source locations remain bytes. SourceRange is always tied to the original pattern and synthetic instructions may have zero-length source spans.
- The executor binds one SemanticProgram in an executor implementing IRegularExecutor. GetRequiredCapacity(operation) reports exact deterministic upper bounds for three Int32 partitions: state, capture registers, scratch/closure/deduplication. Its implementation owns the internal layouts and tests them; Runtime does not interpret those slots. All multiplication/addition, including state × group registers and closure stacks, uses checked wide arithmetic before conversion to array lengths. Overflow is explicit capacity exhaustion, never a truncated request. The generic Search binds the statically specialized text reader; tests may bind independent test readers. One interface dispatch per operation is allowed. No external regex oracle is a production fallback.
- Runtime factories/workspaces bind input/executor types. It admits capacities before constructing RunState over owned spans. The executor cannot grow or rent these spans. Workspace.RequiredBytes conservatively counts three 32-byte array headers plus four bytes per reserved slot (96 + 4*(state+capture+scratch)), including zero-slot arrays; wrapper/profile metadata must be charged additionally if retained per workspace. No extra input-sized heap buffers outside those partitions are permitted without explicit accounted capacity. Caller destinations are not retained or charged as owned workspace storage.

IR instructions have Opcode, X, Y, Operand, Count and SourceRange. X is a continuation; Split visits X before Y, expressing alternation and greedy/lazy priority. Literal holds one legal element; Class holds a class-table index; Any uses the normalized DotAll flag; anchors are absolute; CaptureStart/End use group IDs; ClearCaptures clears Count consecutive groups beginning at Operand (group zero excluded). Jump consumes no input. Match terminates a selected path. All unused operands are zero. The entry is instruction 0 CaptureStart(0); the penultimate instruction is CaptureEnd(0) pointing to the final unique Match. No edge re-enters entry or bypasses the epilogue to reach Match. All edges/source ranges/classes/IDs/opcodes are validated before immutable copies are published. Epsilon cycles are legal and must terminate through bounded executor closure/deduplication, not recursive traversal. Captures are unset internally until open/close establishes participation; repeated groups use explicit clear events. Feature flags describe required execution capabilities, not a substitute syntax manifest.

Compile work charges one unit per inspected pattern unit, AST node constructed/visited, emitted or validated instruction, inspected/copied class interval, copied instruction/class-table entry and interval algebra comparison/output. Each repeated lowering copy counts again. Temporary AST/stacks/range builders and retained pattern/class/program copies must call CompileBudget.TryReserveBytes **before** allocation/growth; reserve the replacement while old capacity remains live, then ReleaseBytes only when the old storage is no longer retained. Peak live memory is independently bounded by MaxCompileMemoryBytes. CharacterClass has a private constructor and a budgeted TryCreate: it checks range/plan/work/live-memory admission before copying. Parser-produced ranges must already have budgeted temporary storage. SemanticProgram validates and charges its defensive copies before allocation. Retained plan accounting conservatively uses 256 metadata bytes + two bytes per original pattern unit + 32 per instruction + eight per class-table reference + 64 per class + eight per interval. Actual larger representations must increase accounting; pools charge rented capacity, not merely requested logical length. Allocation failure/OOM is not an expected syntax diagnostic.

Execution work charges one unit per native unit inspected for validation, decoded element read, candidate advance, instruction visit/closure/deduplication attempt, class interval comparison and Int32 capture/register entry copied/cleared/written. Bulk operations charge their full length before doing the work; no single charge hides an unbounded scan. Successful output capture writing charges each register/slot. One budget survives every candidate/pass/retry. Failure cleanup (bounded logical output clearing and releasing admitted scratch) does not reset the counter or attempt another match. Every instruction/loop, including empty/epsilon transitions, polls via TryCharge; initial zero-charge polling handles empty subjects and immediate acceptance. Limits are deterministic work units, not native-engine counter parity or latency guarantees.

## Corpus and measurement interchange

`test/GregsEx.Tests/Contracts/CoreFixture.cs` and `CoreFixtures.json` freeze nonshipping fixture v1: stable case ID, requirements, source/license/oracle provenance, mode/input kind/pattern unit, numeric exact pattern/input units, operation, original startAt, destination size and structured expected status/range/groups/diagnostic/failure. Numeric arrays preserve lone surrogates and arbitrary bytes. Every fixture carries explicit ProfileId, DataId and Flags; diagnostics include native source offset/length, and execution failures include native position and required capture count where applicable. Fixture v1 admits Parse/Boolean/Range/Captures only: iteration sequences require a separate integration-owned fixture contract and are rejected by this loader, since a single range cannot express them. Tests check fixture admission/interchange; these are hand-authored expected results, not engine execution evidence. Later lanes add their positive/negative/boundary cases in owned directories and reuse these types.

Benchmark cases record stable IDs, input/pattern identities, profile, flags, operation, code revision, runtime, host conditions, preparation/capacity policy, and exact command. Retain raw BDN allocation bytes and operation counts; measure cold parse/growth/convenience costs separately. Compare only equivalent semantics and operations. See [performance.md](performance.md).
